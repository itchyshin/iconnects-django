{% comment %} The Done tick box of one completion-table row — ticked when the assignee's part is marked done, unticked when not. Ticking marks it; unticking undoes it. Expects ``s`` (one entry of views._task_status_context's assignee_states) and ``task``; it swaps #task-status-block, the target every completion action uses. Who may tick it is who could before: a Lead, for anyone (``s.can_mark_done``, posting by member so a row with no entry yet still works), and an assignee for their own part (``s.is_viewer``, through the self-mark endpoints). Everyone else sees it read-only. Once the task is marked completed, the marks a Lead sets for others freeze; an assignee's own box stays live, so whoever had not ticked when the Lead closed it still can, and whoever had can take it back. Unticking clears the part's review and verification with it, even a review given before completion that no one else can withdraw. A frozen box stays clickable but never toggles: a click shows the card's locked notice (``showLocked``, from task_status_block.html) instead, saying the task has to be marked not complete first. {% endcomment %} {% if s.can_mark_done %} {% elif s.is_viewer %} {% elif marks_locked %} {% else %} {% endif %}
