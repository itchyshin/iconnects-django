{% if not standalone and not form.instance.pk %} {% comment %} A new task's editor closed by accident — a click outside it, or Esc — is saved rather than lost, when the form passes its own checks (a name, at least). Cancel and the × discard on purpose: they set data-discard on the dialog first. Save and a successful create close it too, but by then the form has been sent, so nothing is sent twice. The save goes the way Save does, with autosave=1 so the board says so after its reload. If the server turns it down (a rule the browser cannot check), the editor opens again with the errors, nothing typed lost. Edit forms are left alone: closing one keeps the task as it was. {% endcomment %} {% endif %}
