{% comment %} The @ list of a comment box, and the tags it has picked. Included inside a form carrying x-data="mentionBox()" (base.html), right after the textarea, in a wrapper with the classes ``mention-field relative``: relative so the list drops down beneath the box, mention-field for the highlight layer's styles (see .mention-field in base.html). mention_data is {"candidates": [{id, name, email}], "selected": [...]}: the project's contributors, who are the only people who can be tagged, and who already is (an edit). Each is listed by name with their email beneath, and can be found by either. Each pick posts one mentioned_user_ids; the server keeps only those whose @Name (or @email) is still in the text, so a name deleted from the box after it was picked tags no one. An @email typed out in full tags its owner with no pick at all, and so does an @Name typed out in full that no other contributor shares. Each tag is highlighted in the box as it is typed (mentionBox in base.html), and the posted ids are the highlighted people. The list follows the ARIA combobox pattern: the textarea owns it (aria-controls, aria-expanded, aria-activedescendant are set from mentionBox), arrows move, Enter or Tab picks, Escape closes. {% endcomment %} {{ mention_data|json_script }} {# Exactly the people highlighted in the box: see mentionBox.refresh. #}
