It sits above the thread, so a new comment goes in at the top — afterbegin, matching the newest-first order the list is rendered in. Pass target for the thread's id on the surface (the pane's carries the task's pk); it defaults to the full page's #task-comments. The box and its send button share one row. The button is an icon, so its name stays on the page for screen readers. Typing @ opens a list of the people who can open the task; picking one writes @Name into the box and tags them, which emails them (see mention_list.html). Callers draw this only when can_comment: the task's creator, assignees and reviewers. {% endcomment %}
